# 8. The CapCut project format (reference)

Everything here was read from projects CapCut wrote itself (Windows 9.3 and 9.4, Mac 9.5, September and October
2026) and confirmed by generating projects that CapCut opened, played and exported. CapCut can change any of it in
any update, so treat it as a map, and always clone objects from a project your own version wrote.

Open-source projects that write CapCut and JianYing drafts, worth reading:
[pyCapCut](https://github.com/GuanYixuan/pyCapCut), [pyJianYingDraft](https://github.com/GuanYixuan/pyJianYingDraft),
[VectCutAPI](https://github.com/sun-guannan/VectCutAPI). JianYing 6 and later encrypts its drafts; CapCut desktop does
not.

## Where projects live

| | Folder |
|---|---|
| Windows | `%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft\<project name>\` |
| Mac (App Store) | `~/Movies/CapCut/User Data/Projects/com.lveditor.draft/<project name>/` |

- Windows 9.3 and 9.4 write `draft_content.json`. **Mac 9.5 writes `draft_info.json`** (at the root and in
  `Timelines/<id>/`); compound wrappers keep `draft_content.json`. The schema is the same.
- Every main file has mirrors CapCut writes with the same content (`draft_info.json.bak`, `template-2.tmp`). Write all
  three. The `.bak` drifts on its own (float formatting, a disk id), so never demand byte-identical mirrors: the main
  file is the truth.
- CapCut scans the folder **only at startup** and rewrites its own index (`root_meta_info.json`) on exit. Never edit
  while it runs; a new project needs a restart to appear.
- Regenerated by CapCut, leave them out of a generated project: `draft.extra`, `*.bak`, `template*.tmp`,
  `draft_cover.jpg`.

## Units and the basic objects

- **Time is integer microseconds** everywhere.
- A **segment** (a clip on a track) has `source_timerange` (the slice of the file: start, duration) and
  `target_timerange` (where it sits on the timeline).
- A segment points at a **material** (`material_id`). There is **one `materials.videos` entry per segment**, even when
  eight segments use the same file; they share `local_material_id`, the lowercase uuid of the file's entry in
  `draft_meta_info.json` (`draft_materials`, type 0).
- `materials.videos[].duration` is the whole file. For a whole-file segment use the material's own duration: on 9.4 it
  is ms-rounded (`int(dur*1000)*1000`; `int(dur*1e6)` overruns the material by 333 µs); on 9.5 the material duration is
  **ceiled to a frame** and the meta "roughcut" duration is ms exact.
- Every segment carries `extra_material_refs`: a list of ids of small helper materials. A plain video segment has
  seven: `speeds, placeholder_infos, canvases, material_animations, sound_channel_mappings, material_colors,
  vocal_separations`. With audio processing on, CapCut writes them in this order: `speeds, placeholder_infos, canvases,
  realtime_denoises, material_animations, sound_channel_mappings, material_colors, vocal_beautifys, vocal_separations`.
  Clone a real segment with its extras as the template and give every id a fresh uuid.

## Tracks, layers, position

- The **main track** has `flag 0` and its segments `render_index 0`. **A main track cannot have gaps**: to place clips
  at sync offsets, fill the holes with a muted photo (a photo is a `materials.videos` entry with `type "photo"` and a
  duration of 10800 s).
- An **overlay track** (picture in picture) is another `video` track with `flag 2`; its segments get `render_index 1`
  and a `track_render_index` equal to its stacking position.
- A **text track** has `flag 1`.
- **Mute a clip:** `volume 0.0` and `last_nonzero_volume 0.0`. Keep `last_nonzero_volume 1.0` and the clip is muted with
  the slider ready. Track `attribute 1` = the speaker icon at the track head; muting the main track also sets
  `config.video_mute`.
- `clip.transform` is in **half-canvas units**: `x = 1` puts the clip's centre on the right edge; `y` positive is up.
  `clip.scale` is relative to the **contain-fit** size: a 9:16 phone clip in a 4:5 canvas at scale 1.42 fills the
  width. Canvas: `canvas_config {ratio: "original" | "9:16", width, height}`.
- **Rotated phone files:** a 3840x2160 file with rotation -90 is stored with the **displayed** size (2160x3840) in
  `materials.videos` and in `draft_meta_info`, no rotation field, `clip.rotation 0`. At scale 1 it fills a 1080x1920
  canvas.
- **Snap zoom** of Z around a point (cx, cy) in frame fractions: `clip.scale = Z`, `transform.x = -2 (cx - 0.5)(Z - 1)`,
  `transform.y = +2 (cy - 0.5)(Z - 1)`. Push-ins are `common_keyframes` of type `UNIFORM_SCALE`.

## Side files

| File | What |
|---|---|
| `draft_meta_info.json` | draft id, name, folder path, `draft_materials` grouped by type (type 0 = imported files with `file_Path`, duration in µs as ms x 1000, width, height; type 18 = compounds), `tm_*` timestamps in µs |
| `draft_settings` | INI |
| `draft_virtual_store.json` | one child per material |
| `timeline_layout.json` | `dockItems[0].timelineIds` and `timelineNames`, in order |
| `Timelines/project.json` | `timelines[]` (id, name) and `main_timeline_id` |
| `Timelines/<id>/draft_info.json` | one full timeline each; the root file is a copy of the main timeline |
| `common_attachment/attachment_id_mapping.json` | short ids (1000+) to segment uuids; new compound segments get appended |

**Meta groups:** clone `draft_materials` from a project that has every type. A template project with no compounds has
no type-18 group, and compounds then never appear in the media panel.

## Compound clips (CapCut's nested sequence)

A compound lives in **three places that must match**:

1. **Embedded in the parent:** a `materials.drafts` entry, `type "combination"`, with an `id`, a `combination_id`, and
   the whole inner timeline embedded in its `draft` field. The parent segment lists this entry's id **first** in its
   `extra_material_refs`. Its video material has `extra_type_option 2`, `path ""` and `material_name` = the compound's
   name. New compounds go with `precompile_combination: false`.
2. **The wrapper:** `subdraft/<folder id>/draft_content.json`, a one-segment draft (fresh id, empty name, canvas
   `original` 0x0, duration 0) whose `drafts` material has the **same `id` and `combination_id`** as the parent's and
   an identical inner draft. Paths inside use a placeholder (`##_draftpath_placeholder_<uuid>_##` on 9.4,
   `##_subdraft_placeholder_<uuid>_##` on 9.5). Plus `sub_draft_config.json`: `{id, project_id (= the folder id), name,
   rough_cut_duration, is_from_sub_draft: true, source: "timeline"}` and a 180x320 cover.
3. **The meta entry:** a type-18 entry in `draft_meta_info.json` (`metetype "combination"`,
   `file_Path "./subdraft/<folder>/sub_draft_config.json"`), and `config.combination_max_index` = compounds + 1.

More facts that cost us time:

- **Every timeline holds its own copy of each compound.** The same take used in three ads is three compounds. An
  overlay or a gain change goes into each copy.
- On the Mac, wrappers inherited from a Windows project are often stale. The truth is the copy embedded in each
  timeline.
- **A compound placed twice on one timeline** (split to drop a pause) is still one compound: one overlay inside it
  covers both pieces.
- **A take as a compound with handles:** inside, the raw clip at 0 with `source_timerange.start` = the span start and
  the whole span's duration; outside, the parent segment's `source_timerange` is the tight cut. Compound time = take
  time, so caption and overlay times never need converting.

## Captions (as auto-captions writes them)

- `materials.texts` entries of `type "subtitle"`, with `recognize_task_id` (24 hex characters + `_8_0`) listed in
  `config.subtitle_taskinfo` (type 10), a `group_id` like `es-MX_<epoch ms>`.
- `content` and `base_content` are JSON strings; their `styles[].range` must equal `[0, len(text)]`. **After a hand edit
  CapCut can leave `base_content` with the old words**: that is the glitch where "one or two words look different".
  Normalize the ranges of every caption.
- Style at material level: `letter_spacing -0.05` (= -1 in the UI), `font_size 30`, `fonts[0].title "Poppins-Bd"`.
- `words`: word and space tokens with times in **ms from the caption's start**.
- `extra_info.subtitle_fragment_info_list`: a contiguous partition of the compound (speech fragments carry a cached
  sentence with **absolute** ms word times; gaps carry an empty string).
- Caption segments: `source_timerange null`, `render_index 14000 + i`, `track_render_index 1`, `clip.transform.y
  -0.56`, one `material_animations` extra of `type "caption"`. The animation "Bounce Out" on a phrase caption with
  per-word timing is what shows **one word at a time** (checked frame by frame on an exported piece). Its duration =
  the longest caption of the group. Snap caption times up to the frame from the recognizer's 40 ms grid.

## Audio objects

- **Reduce noise** = a `realtime_denoises` extra on the segment that carries the audio: `is_denoise true`,
  `denoise_rate 0.85`, `sami_name denoise_v2`, and a model path inside the app (on the Mac,
  `/Applications/CapCut.app/Contents/MacOS/../Resources/audiosami/unet_denoise_44k_music_model_v1.0.model`). **Off =
  `is_denoise false`**: the material and its ref stay, exactly what CapCut writes when the toggle is switched off.
- **Enhance voice** = a `vocal_beautifys` extra: `enable`, `ambient_sound_level` (the % slider), `time_range` = the clip
  range, and a `production_path` to a processed wav CapCut renders itself (`<project>/Resources/audioAlg/...`). A
  generated project has no processed wav yet; toggling Enhance voice off and on in the app makes CapCut render it.
- **A local audio file (9.5):** a `materials.audios` entry with `type "extract_music"`, `category_name "local"`, a fresh
  lowercase `music_id`, `local_material_id` = its meta type-0 id (`metetype "music"`, width and height 0),
  `check_flag 1`, `app_id 0`, a 32-hex `unique_id`. Extras: `speeds, placeholder_infos, beats, [realtime_denoises],
  sound_channel_mappings, vocal_separations`. Library sounds (`type music` or `sound`) are not meta entries.
- **Gain:** linear, `10^(dB/20)`. Our transition whoosh sits at 0.634 (63 %) everywhere.

## Markers and transitions

- **A marker (M key)** = a `materials.time_marks` entry `{id, mark_items: [{id, time_range: {start, duration: 0},
  color: "#00c1cd", title}]}` referenced **first** in the segment's extras, mirrored by a `beats` extra whose
  `user_beats` list the same starts.
- **A transition** = a `materials.transitions` entry (name, effect id, path to its cached effect, duration in µs,
  `is_overlap false`) referenced from the **outgoing** segment's extras, right after its `placeholder_infos` ref.

## Overlays inside a compound

To put a transparent overlay inside a take's compound so it survives every re-trim: append a `flag 2` video track to
the inner draft with the overlay at 00:00 for the whole compound length (segment `render_index 1`,
`track_render_index` = the number of video and text tracks), using extras cloned from an overlay CapCut itself saved;
write the same into the wrapper; add a type-0 meta entry and a virtual-store child. Captions keep rendering on top.

- **Never clone the take's audio extras onto the overlay** (Reduce noise and Enhance voice belong to the take).
- **Replace an overlay under a new file name** (`part-v2.mov`, `part-v3.mov`) and repoint, never overwrite in place:
  compounds can be pre-rendered (`Cache/prerender/<timeline id>/`) and an in-place overwrite risks a stale picture.
- **A longer overlay** means extending the overlay segment, the compound's duration, the parent's compound material,
  the wrapper and `rough_cut_duration`.

Code that does this: [`code/vsl-motion/tools/place_capcut.py`](../code/vsl-motion/tools/place_capcut.py).

## Debugging what CapCut actually did

- To see the frames CapCut really decoded (not what the JSON says): its thumbnail cache, `Cache/frameThumbnail/
  <hash>/<W>x<H>/<µs>.png`.
- The timeline duration is `duration` (µs) in the timeline file; exports matched it to the frame.
- A Windows project opened on the Mac relinks font and effect paths only for the timeline opened first. The other
  timelines show "Poppins" in the panel but render a fallback font without the caption animation, until the paths are
  rewritten to the Mac cache.
- CapCut Mac's logs are binary: not greppable. Their file names are launch timestamps.
