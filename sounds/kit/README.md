To render the same takes yourself (they come out identical, sample for sample):

```bash
cp -R sounds/kit /tmp/kit && "$EARSHOT_HOME/.venv/bin/python" -m earshot kit render \
  code/sound-effects/kits/ads-grown-2026-11.json --out /tmp/kit      # every take reads "cached"
```
